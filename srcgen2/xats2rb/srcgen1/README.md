# xats2rb

`xats2rb` is the ATS3/Xanadu-to-Ruby code generator in this
directory. It reads an ATS3 source file, processes it through the
Xanadu compiler pipeline, and emits Ruby code. By default, the output
is a standalone Ruby program with the xats2rb runtime helpers and the
srcgen2 prelude included.

The backend is based on `xats2pl`, the ATS3/Xanadu-to-Perl code
generator. Nearly all of `xats2rb` is generated by Codex.

Last updated: October 18, 2026.

## Usage

Build the compiler from this directory with `make`, then run:

```sh
./bin/xats2rb path/to/program.dats -o program.rb
ruby program.rb
```

Without `-o`, generated code is written to standard output. Compiler
flags can be passed through after the source path; run `./bin/xats2rb
--help` for the launcher's options.

Use `--emit-only` to omit the runtime and prelude when you want just
the generated Ruby:

```sh
./bin/xats2rb --emit-only path/to/program.dats -o generated.rb
```

## How it works

The launcher in `bin/xats2rb` invokes the generated JavaScript
compiler in `UTIL/`. That compiler parses and translates the source
into the internal `i1` representation, then `rb1emit` emits Ruby. The
command-line compiler is built from the ATS implementation and its
compiler/runtime dependencies; `UTIL/Makefile_xjsemit` describes the
build inputs.

The main implementation is in `DATS/` and `SATS/`. Ruby support code
lives in `xshared/runtime/`: `xats2rb_rb1emit.rb` provides helpers
expected by emitted code, and `srcgen2_prelude.rb` supplies the
Ruby-side prelude. `TEST/` and `prelude/TEST/CATS/RB/` contain example
ATS programs and Ruby-targeted prelude tests.

This is a source-generation backend, not a Ruby interpreter: generated
programs require Ruby, and available behavior depends on the constructs
implemented by the backend and the included prelude/runtime.
