01 / THE PHILOSOPHY

Start simply.
Go deeper.

Powerful types should open doors. ATS3 revisits the design of ATS to make that power more accessible, one layer at a time.

01 —

A gentler first step

Start with ML-like algebraic type-checking. Programs that pass this layer can be compiled and executed without requiring dependent type-checking.

APPROACHABILITY
02 —

Room for deeper reasoning

The design adopts a two-layered approach inspired by Dependent ML, giving advanced type-checking its own place in the language.

EXPRESSIVENESS
03 —

Templates, rethought

Type-based metaprogramming uses algebraic types for template selection, addressing a source of complexity in ATS2.

METAPROGRAMMING
02 / UNDER THE HOOD

A compiler that
compiles itself.

On March 29, 2025, ATS3 successfully bootstrapped via JavaScript. Explore the journey from source text to executable code.

FROM TEXT TO STRUCTURE

Give source code a shape.

Handwritten lexing and parsing turn source text into a level-0 abstract syntax tree. Subsequent passes resolve operator fixity and name bindings.
